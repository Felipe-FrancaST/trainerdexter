# TrainerDex v47

- Ao clicar nos espaços livres do time na aba Jogadores, o Mestre abre o seletor para adicionar Pokémon diretamente.
- O seletor prioriza captura para espaços livres e permite mover um Pokémon existente do PC para o time.
- O acesso Mestre/Jogador é lembrado no armazenamento local deste navegador, sem armazenar a senha; o botão Sair remove essa preferência.
- Ao atualizar a página, restaura também a aba atual quando permitida para o perfil.
- Evita recarga automática forçada durante a troca do service worker.
- Atualiza versão dos arquivos estáticos para v47.

**Atenção:** a restauração de acesso é uma conveniência para campanhas entre amigos, não uma autenticação segura. Não usar em dispositivos compartilhados sem clicar em Sair.
